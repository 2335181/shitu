# 拾图（工作名）安卓应用开发规格

版本：v0.1 · 日期：2026年11月25日 · 状态：需求已确认，P1 开发中

> 应用名「拾图」、包名 `app.shitu` 均为占位，发布前确定。

## 1. 产品定位

一个纯本地运行的安卓素材工具：以图搜图、各平台分享链接解析与原图/视频下载、B站收藏集与装扮素材下载、GIF/实况/动态照片转换。

素材来源：

- 求原图（hiyufan/shizhen，MIT）：功能类目与解析逻辑，**用 Kotlin 移植并保留署名**。
- 手机收藏集图片下载器 7.1.7 的分析结果：**只参考接口与字段，不复制其代码**（无开源许可）。

## 2. 兼容性与技术基线

| 项 | 约定 |
| --- | --- |
| 系统 | minSdk 31（Android 12）、targetSdk / compileSdk 37 |
| ABI | 仅 `arm64-v8a` |
| 语言 / UI | Kotlin 2.4、Jetpack Compose（BOM 2026.11.01）、Material 3 |
| 构建 | AGP 9.5.2（内置 Kotlin 支持）、Gradle 9.9.2、JDK 21 |
| 导航 | Navigation 3，四个标签各自独立返回栈 |
| 网络 | OkHttp 5 + kotlinx.serialization |
| 图片 | Coil 3 |
| 存储 | DataStore（偏好与工作台状态）、Room（下载任务，P1 起） |
| 毛玻璃 | Haze 2.x（底层为 Android 12 `RenderEffect`） |
| 视频平台通用解析 | youtubedl-android（内置 Python + yt-dlp + FFmpeg），**应用内一键更新 yt-dlp** |
| 媒体转换 | Media3 Transformer + FFmpeg |
| 依赖注入 | P1 手写 `AppContainer`，规模变大后评估 Hilt |

依赖版本以 `gradle/libs.versions.toml` 为准，每个版本发布前检查一次更新。

## 3. 导航结构

悬浮底部导航栏：圆角胶囊、离屏幕边缘留空、背景为内容模糊 + 半透明着色（Haze），内容可在其下滚动。

| 序号 | 标签 | 内容 |
| --- | --- | --- |
| 1 | 识图 | 以图搜图（主页） |
| 2 | 工具 | 求原图功能类目罗列；点击某功能 → 打开到「工作台」 |
| 3 | 工作台 | 当前/上次使用的功能页面 |
| 4 | 我的 | 关于、设置、赞助、开发者选项 |

全局下载队列入口：顶栏下载图标 + 导航栏「工作台」角标显示进行中任务数。

## 4. 识图（主页）

**图片来源**：系统照片选择器（PickVisualMedia）、拍照（TakePicture → FileProvider）、剪贴板图片、其他应用「分享到本应用」（`ACTION_SEND image/*`，最常用）。

**预处理**：可选裁剪；上传前压缩到合理尺寸（长边 ≤ 2048，可在设置调整）。

**引擎分两类：**

| 类型 | 引擎 | 展示方式 |
| --- | --- | --- |
| 接口型 | SauceNAO（用户填 API Key）、trace.moe、IQDB、ascii2d | 应用内结果卡片：缩略图、相似度、来源链接 |
| 网页型 | Google Lens、Bing、Yandex、百度识图、搜狗、TinEye | 上传后用 Custom Tabs / 内置 WebView 打开结果页 |

**聚合页**：一次选图，勾选多个引擎并行请求；接口型结果按引擎分组卡片展示，网页型显示「打开」按钮。各引擎独立加载状态，单个失败不影响其他。

引擎列表与启用状态可在设置中排序与开关。各引擎上传接口需实测后固化，接口变化时只改对应适配器。

## 5. 工具（求原图功能类目）

按类目罗列，未实现的标「即将推出」。点击 → 设置为当前工具 → 切到「工作台」标签。

| 类目 | 功能 | 实现方式 |
| --- | --- | --- |
| 链接解析 | 抖音、小红书、快手、B站、YouTube、X、Instagram、Threads、TikTok、公众号、Telegram 公开帖等 | 专用 Kotlin 解析器优先；通用平台走 yt-dlp |
| B站素材 | **收藏集下载**、**装扮下载** | Kotlin 实现，见第 7 节（P2 首个落地功能） |
| 直播 | 抖音直播流地址 | 只给地址，不录制 |
| 音乐封面 | QQ 音乐、网易云、Apple Music、华为音乐 | 静态 / 动态封面 |
| 游戏素材 | Steam 动态头像/头像框/背景、HoYoPlay 壁纸、鸣潮壁纸 | |
| 插画 | Pixiv（插画/漫画/小说/Ugoira/Sketch）、Pinterest、米游社 | |
| 贴纸表情 | Telegram、Discord、LINE、Signal、7TV/BTTV/FFZ、Noto 动态 Emoji | |
| 文件提取 | Wallpaper Engine PKG/TEX | 本地文件 |
| 动画转换 | SVGA（含 B站 `.bin`）、PAG、VAP、Spine | 本地渲染 |
| 转换 | 视频 → GIF / iPhone 实况 / 安卓动态照片；本地视频上传 | Media3 + FFmpeg |

**链接自动识别**：应用回到前台时读剪贴板（Android 12+ 会弹系统提示，需在设置可关闭）；接收 `ACTION_SEND text/plain`。按域名匹配平台 → 打开对应工具并预填链接。

## 6. 工作台（上次使用）

- 状态只有一份：「当前工具 ID」+ 每个工具自己的持久化状态（输入、结果列表、选中项）。
- 写入 DataStore（工具 ID）与工具各自的状态存储（JSON 文件或 Room）。重启应用、切换标签、进程被杀后都恢复。
- 从未用过时显示空态：最近可用工具推荐 + 「去工具页」。
- 工作台顶部可快速切换最近 5 个工具。

## 7. B站收藏集与装扮

**入口**：名称搜索、act_id、近期活动、粘贴详情页链接（`/h5/mall/digital-card/home?act_id&lottery_id`、`/h5/mall/suit/detail?id`）。

**名称搜索**：内置 1,836 条活动目录（来自 7.1.7 分析的 `catalog.json`，`$$` 后为别名，参与匹配不显示）+ 商城搜索 `/x/garb/v2/mall/home/search`；按 act_id 合并，本地优先展示，远端补充。

**接口（合并两方案）**，主机 `https://api.bilibili.com`，请求头带浏览器 UA 与 `Referer: https://www.bilibili.com/`：

| 用途 | 接口 | 来源 |
| --- | --- | --- |
| 搜索 | `/x/garb/v2/mall/home/search?key_word=` | APK |
| 近期活动 | `/x/vas/dlc_act/act/list?scene=1&site=0` | APK |
| 卡池详情（含卡池选择） | `/x/vas/dlc_act/lottery_home_detail?act_id&lottery_id` | 求原图 |
| 卡片/兑换奖励/头像框 | `/x/vas/dlc_act/asset_bag?act_id&lottery_id&ruid=0` | APK（lottery_id 可选） |
| 活动信息/勋章/封面/卡池列表 | `/x/vas/dlc_act/act/basic?act_id` | APK |
| 表情权益 | `/x/vas/user/dlc/right/landing?act_id` | APK |
| 旧式表情 / 完整装扮 | `/x/garb/v2/mall/suit/detail?item_id[&part=suit]` | 两者 |

**资源分类**：卡片图片、卡片动态视频、兑换奖励卡、静态表情、动态表情、头像框、勋章、封面、装扮壁纸/背景（`head_myself_mp4_bg`、`head_myself_bg` 等 13 种属性）、装扮动画（SVGA `.bin`）。

**水印版本**：卡片提供两套地址（`card_img` / `card_img_download`、`video_list` / `video_list_download`），界面以「无水印 / 有水印」切换，并注明：这是服务器提供的两个版本，**不做去水印处理**，不承诺分辨率。缺失版本时按钮置灰。

**安全**：素材域名白名单 `hdslb.com`、`bilivideo.com`（及子域）；校验 `code == 0` 与返回 ID 一致；`video_list` 多地址视为 CDN 备份，下载失败时依次换下一个。

**批量**：按分类全选/多选 → 进入全局下载队列。

## 8. 全局下载管理

- 单一队列，并发上限默认 3（可调）；状态 QUEUED / RUNNING / SUCCEEDED / FAILED / CANCELLED。
- 显示进度（总长未知时显示已下载字节，不伪造百分比）、取消、重试、全部重试。
- 保存：默认 MediaStore `Pictures/拾图`、`Movies/拾图`，写入时 `IS_PENDING`，失败删除半成品。
- **自定义保存文件夹**：设置中可用系统文件夹选择器（`OpenDocumentTree`）选任意目录，持久化 URI 权限（`takePersistableUriPermission`），之后经 SAF `DocumentFile` 写入；可按类别（图片/视频）分别设置，可一键恢复默认。目录失效（被删、权限被收回）时提示并回退默认。
- 校验响应类型，防止把 HTML/JSON 错误页存成图片。
- 后台：前台服务通知显示进度（`dataSync` 类型），用户主动发起。

## 9. 我的（关于与设置）

- 版本信息、检查更新（GitHub Releases API，比对 tag）。
- **yt-dlp 版本与一键更新**（稳定 / 每日构建通道）。
- 主题：跟随系统 / 浅色 / 深色；配色：**跟随壁纸取色（Material You）/ 固定品牌色**。
- 下载位置、并发数、剪贴板识别开关、识图引擎管理、SauceNAO API Key。
- 登录态（可选）：
  - **B站：扫码登录 + 短信验证码登录**（原生实现，接口参考 renmu123/biliAPI，整理见 `docs/B站登录接口.md`）。扫码：应用内显示二维码，轮询状态（未扫码/已扫码待确认/过期/成功）；短信：极验人机验证在 WebView 内完成，再发短信、登录。登录后定期检查并刷新 Cookie，支持退出登录。
  - 小红书：内置 WebView 登录。
  - **yt-dlp 登录态**：「账号管理」页按站点（YouTube、X、Instagram、抖音、B站等）用内置 WebView 登录一次，登录后从 `CookieManager` 导出该站 Cookie，生成 Netscape 格式 cookies 文件（加密保存，运行时解密到私有临时文件，用完删除），下载时自动传 `--cookies`。显示各站登录状态与过期提示，可单独退出；也支持导入 cookies.txt。B站扫码/短信登录的 Cookie 同步给 yt-dlp。
  - Cookie 用 Android Keystore 加密保存，仅附加到对应平台域名；可一键退出清除。
- 清理缓存（显示占用）。
- 赞助（收款码图片）。
- 开源许可（含求原图 MIT 署名、各依赖许可）、免责声明。
- 开发者选项（连点版本号 7 次开启）：网络日志查看与导出、接口地址覆盖、导出调试信息（版本、设备、最近错误，自动脱敏 Cookie）。

## 11. 分阶段计划

| 阶段 | 范围 | 验收 |
| --- | --- | --- |
| P1 骨架 | 工程、主题（动态取色/品牌色）、悬浮毛玻璃导航栏、四标签、工作台状态持久化、工具目录、关于页框架 | 能编译安装；切换标签/重启后工作台保持 |
| P2 | B站收藏集与装扮完整功能、全局下载队列、识图（选图/裁剪/分享入口/聚合页） | 真机下载图片、视频、表情入相册 |
| P3 | youtubedl-android 接入与应用内更新、通用链接解析、剪贴板/分享识别 | 主流视频平台可下载 |
| P4 | 专用解析器逐个移植（抖音、小红书、Pixiv…）、GIF/实况/动态照片转换、登录态 | 每个解析器有真实链接验证记录 |
